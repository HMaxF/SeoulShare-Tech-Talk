RAG & AI Agents: From Chatting to Doing Real Tasks

⏱ Duration: 15 minutes

🎯 Goal: Understand how AI goes from "answering questions" to "solving problems"

“By the end, you will understand how AI can act as your personal researcher and digital employee.”

What is RAG?

RAG = Retrieval-Augmented Generation

  • A technique that gives LLM a "library of facts" from some documents (database, texts, JSON, Internet, etc.) to look at before answering.
    * To improve accuracy.
  • It solves the problem of LLM "forgetting" recent facts or making things up.
    * To reduce hallucination

Why RAG is Important?

  • LLM knowledge is limited or maybe outdated and LLM alone can not access external (or private) data.

How RAG Works?

  1. User asks question
  2. Search relevant documents
  3. Inject context into prompt
  4. Send to LLM to generates answer
The Analogy: The "Open-Book Exam." Instead of guessing from memory, the RAG reads/queries external files/data to find the right answer then use LLM to rephrase the answer.

What is an AI Agent?

AI Agent = AI that can take actions, not just answer.

  • Understands a goal
  • Makes decisions
  • Uses tools
  • Executes tasks

How AI Agent Works?

  1. Receive goal
  2. Plan steps
  3. Use tools (API, browser, etc)
  4. Execute
  5. Repeat until done
The Analogy: AI Agent is a "Digital Employee", a "doer" with hands.

RAG + AI Agent + LLM: working together

  • 🧠 RAG = Brain (knowledge)
  • 👐 Agent = Hands (action)
  • 🗣 LLM = Voice (communication)

Powerful combination!

"RAG gives AI the knowledge.

What are the Challenges?

  • Data Privacy: You must be careful about which documents you give the "library."
  • Agent "Loops": Sometimes an agent can get stuck trying to solve the same problem repeatedly.
  • Cost: Running many searches and actions can use more "AI fuel" than a simple chat.
  • Wrong Actions: If not controlled, an AI agent could send wrong emails or make wrong bookings.

F.A.Q

  • Is RAG better than training a new AI? Yes! RAG is much cheaper and faster. You can update your "library" in seconds, whereas training an AI takes weeks.
  • Can an AI agent accidentally delete my files? Yes, it's a risk! AI agent can autonomously take actions and it may do something wrong, that is why we use "Human-in-the-loop"—the Agent asks for your permission before taking a final action.
  • Do I need to be a coder to use these? No. Tools like "Custom GPTs" or "Agentic Workflows" now allow you to build these using just plain English.
  • Can OpenClaw be considered as a type of AI agent? Yes, OpenClaw is designed to interact with tools (like browser, apps, files) to finish it given tasks. It is like we give OpenClaw a mouse and keyboard to simulate human to work.

Sample RAG (with Python) to search Internet and get brief content

from ddgs import DDGS
import sys

def reliable_ddgs_search(query, num_results=3):
    links = []
    try:
        # Perform search using DuckDuckGo
        with DDGS() as ddgs:
            results = ddgs.text(query, max_results=num_results)
            if results:
                for r in results:
                    # Depending on DDGS version, the URL key is 'href' or 'link'
                    links.append(r.get('href', r.get('link', '')))
    except Exception as e:
        print(f"Error during search: {e}")
        
    return links

def get_top_3_content(query):
    print(f"🔎 Searching for: {query}\n")
    
    # 1. Search using DDGS and get top URLs
    links = reliable_ddgs_search(query, num_results=3)
    
    if not links:
        print("❌ Oops! Search returned 0 results. It is likely the request was blocked or DDGS encountered an error.")
        return
        
    for i, url in enumerate(links, 1):
        print(f"🌐 Result #{i}: {url}")
        
        try:
            text = DDGS().extract(url, fmt="text_plain")
                  
            # Show just the first 300 characters as a preview
            print(f"📄 Content Preview: {text['content'][:300]}...")
            print("-" * 30)
            
        except Exception as e:
            print(f"❌ Could not read this page: {e}")

def main():
    # Receive query from command line
    # $ python3 rag-search-google.py nomor cantik
    if len(sys.argv) > 1:
        query = " ".join(sys.argv[1:])
    else:
        query = "Latest AI news March 2026"  # default fallback
        
    get_top_3_content(query)

if __name__ == "__main__":
    main()
