What Is Vibe Coding?

  • Vibe Coding is the process of building software by collaborating with an AI coding agent using natural language instead of writing every line of code yourself.
  • Many modern IDE (Interface Development Editor) already have built in AI Agent to help developers build applications more efficiently and effectively.
  • Due to intense competition and rapid improvements in AI technology, there are now many powerful AI models available for free.
  • Writing on these IDEs become faster and AI is smart enough to provide inline suggestions and complete the code or text sentences.
    * Using these IDE and AI Agent can help non-technical such as writers to create content or reports or visualize data and presentations.
Today, vibe coding is not only become more easy but it is unavoidable not to use it.

Prompting VS Instructing

Prompting

  • We ask questions.
  • We ask AI to think.
  • We ask AI to explain.
  • We ask AI to summarize.
  • We ask AI to read file(s).

Instructing

  • We tell AI to build.
  • We tell AI to modify.
  • We tell AI to execute tasks.
  • We tell AI to read and write files.
  • We tell AI to use tools.
    * (Terminal, Git, etc.)
Prompting is to ask simple question, instructing is to tell AI to work to complete a task.

What is the best tool for Vibe Coding?

There are so many available IDEs, AI Agents and AI Models to choose.

IDE: Microsoft VS Code, Google Antigravity, Cursor, etc.

AI Agents: Cloude Code, Codex, Gemini CLI, OpenCode, etc.

AI Models: GPT-5, Cloude Sonnet, Gemini, DeepSeek, Qwen, etc.

Choosing the right combination is challenging, and some of them have cost and can get quite expensive, personally I use what I can afford ... and it is free 😄

The best tool is useless if it can not read our mind, how to create better instruction is more important than the tool.

How to give instruction to AI Agent?

No strict guideline, this is my personal structure to create web applications, write in markdown and split the content like:

  1. agent.md: Main description of the project
    * Mention all other required instruction *.md files for AI Agent to know.
  2. backend.md: Requirement for admininistrator and content manager.
  3. frontend.md: Feature and design for public visitor page.
  4. database.md: Tables' schemas.
  5. etc.

For simple projects, I usually write the instruction in a single file.

  • My own Tetris clone implementation for responsive design: Tetris Clone
  • Example of tetris game, my original spec: Written original spec
  • After game is completed then I asked AI to generate a more complete instruction for other AI to re-create the game: Instruction from AI to AI
We can ask AI to generate a more complete instruction for other AI, just to compare the result if other AI can do better.
