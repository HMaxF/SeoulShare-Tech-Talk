History of LLM

LLM stands for Large Language Model.

LLMs are AI systems trained on massive amounts of text to understand and generate human-like language.

  • Before 2017: Rule-based & simple machine learning (limited)
  • 2017: Transformer architecture (breakthrough)
  • 2020: GPT-3 shows strong language ability
  • 2022: ChatGPT becomes first widely used public AI

First public breakthrough: ChatGPT (OpenAI, 2022)

How to Build an LLM?

Building an LLM is complex and requires huge resources:

  1. Collect massive text data (books, websites, code)
  2. Train a neural network (millions to billions of parameters)
  3. Use powerful GPUs (weeks/months of training)
  4. Fine-tune with human feedback

Reality: This costs millions of dollars 😄

Good news: You don’t need to build one—you can download and run one locally!

How LLM Works?

LLM works like a very smart “next word predictor”.

  1. You type a question
  2. Model predicts the most likely next word
  3. Repeats this process very fast

Important:

  • It does NOT “think” like a human
  • It predicts based on patterns in data

💡 Example: “The capital of Korea is…” → “Seoul”

What is LLM Hallucination?

Hallucination = when AI gives a confident but wrong answer.

  • AI may invent facts
  • AI may give outdated info
  • Sounds correct, but is wrong

Example:

Asking for a book reference → AI may create a fake book that doesn’t exist

Lesson: Always verify important information ✅

Models for Low RAM (No GPU)

Good models for normal laptops:

  • Phi-3 → very small, fast
  • Gemma → lightweight, stable
  • Mistral (7B) → good balance

Minimum requirement:

  • 8GB RAM → OK
  • 16GB RAM → Better experience

💡 Tip: Choose “4-bit quantized models” for faster performance
