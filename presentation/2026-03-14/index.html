History of HTML

HTML stands for HyperText Markup Language. It is the language used to create web pages on the internet.

HTML was created in 1991 by Tim Berners-Lee, a scientist working at CERN. His goal was to help researchers easily share documents and link information between computers.

The idea was simple: documents could contain links that connect to other documents. This concept became the foundation of the World Wide Web.

HTML header

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Story 1</title>
</head>
<body>
    <!-- start of your actual page content -->
    
    Hello World!
    <br>
    I wish today is weekend!

    <!-- end of your actual page content -->
</body>
</html>

Working with Github

  1. Create index.html
    • Create Github account
    • Create a new repository, enter repository name, eg: "my_first_web_page".
      • Choose visibility as "Public".
      • Turn on option "add README".
      • Click "Create repository" button.
    • Create a new file.
      • Click "add file" -> Create new file.
      • In input box filename: enter 'www/' (NOTE: type '/' at the end) then 'index.html' -> this will create a new directory 'www' and create a new file named 'index.html' inside it.
      • Click the button "Commit changes".
      • In commit message: 'create my first index.html' or whatever message to remind yourself about this action.
  2. Write HTML code file
    • Go back to main screen by clicking the "Code" tab on top-left.
    • Open Github dev (file editor) by typing "." with your keyboard, web url will changed, eg: https://github.dev/HMaxF/html_for_beginner/tree/main/www
    • Highlight the "index.html" under "www" directory.
    • Type '!' (exclamation mark) then enter, it will create the standard HTML header.
    • Between the HTML tag <body>...</body>, type something, eg: Hello world, how are you?
    • Commit the new changes by:
      • Click "Source Control" on left-side menu.
      • Stage the changes, select which file to update by click the "+" icon on the file.
      • Add label of what changes (for self reminder)
      • Click "Commit & Push" to save
  3. Deploy to Github Pages
    • Go back to the repository, eg: https://github.com/HMaxF/html_for_beginner
    • Click Settings -> Pages, eg: https://github.com/HMaxF/html_for_beginner/settings/pages
    • Select Branch: main
    • Click Save button!
    • Congratulation 🎉, you have a web page
